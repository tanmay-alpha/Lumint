## 7. Remaining Backend Risks

* **Local JSON Store is Demo-Grade**: The database resides in `fraud_events.json` which works well for offline demos and local setup, but does not provide transaction isolation or concurrency locks.
* **No Production Database Yet**: Transition to a database like PostgreSQL is required for multi-tenant, concurrent production usage.
* **Local File Uploads are Demo-Grade**: Uploaded files are written directly to local disk (`backend/uploads/`), which requires persistent disk volumes in a containerized environment (e.g. AWS EBS, S3).
* **Forensic Scoring is Signal-Based, Not Proof-Based**: The risk scoring uses combined signals (empty creator, date mismatch, font anomalies) to flag high-risk documents; it is a screening mechanism and not concrete forensic proof of forgery.
